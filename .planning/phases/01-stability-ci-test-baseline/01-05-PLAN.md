    Contents:
    ```spec
    # Phase 1 dry-run RPM spec — NOT for signing or distribution.
    # DIST-02 in Phase 6 adds signing, GPG keys, and real release pipeline.

    Name:           teraguchi-server
    Version:        3.0.0
    Release:        1%{?dist}
    Summary:        Teraguchi remote workstation server — Rocky Linux 9

    License:        ASL 2.0
    URL:            https://github.com/thedepartmentofexternalservices/teraguchi
    Source0:        %{name}-%{version}.tar.gz

    BuildArch:      noarch
    BuildRequires:  python3.12
    BuildRequires:  python3.12-pip

    Requires:       python3.12
    Requires:       ffmpeg-free
    Requires:       xorg-x11-server-Xvfb
    Requires:       pulseaudio-utils

    %description
    Teraguchi server — open-source remote workstation for VFX / Flame workflows.
    Replaces HP Anyware (PCoIP) for small independent VFX studios.

    Phase 1 dry-run spec. Signing + distribution land in Phase 6 (DIST-02).

    %prep
    # Phase 1 dry-run — no actual unpack needed for --buildonly.
    %autosetup -n %{name}-%{version} -c -D 2>/dev/null || true

    %build
    # No compilation step — pure Python. Real packaging lands in Phase 6.
    echo "Phase 1: dry-run only. No artifacts produced."

    %install
    # Dry-run: no install step.
    mkdir -p %{buildroot}%{_bindir}
    # Phase 6 DIST-02 will install a systemd unit + launcher script.

    %files
    # Empty — this spec's purpose is to validate syntax only.

    %changelog
    * Fri Apr 18 2026 Randy McEntee <randy@thedepartmentofexternalservices.com> - 3.0.0-1
    - Phase 1 dry-run RPM spec (no signing, no distribution).
    ```

    **Key decisions:**

    - `BuildArch: noarch` — pure Python, no compiled artifacts

    ```yaml
    name: Build artifacts

    on:
      pull_request:
        branches: [dev, main]
      push:
        branches: [dev, main]

    concurrency:
      group: ${{ github.workflow }}-${{ github.ref }}
      cancel-in-progress: true

    jobs:
      build-mac-app:
        name: PyInstaller .app (macos-14 arm64 dry-run)
        runs-on: macos-14
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-python@v5
            with:
              python-version: "3.12"
          - uses: actions/cache@v4
            with:
              path: ~/.cache/pip
              key: pip-build-mac-${{ hashFiles('requirements-*.txt') }}
          - name: Install build deps
            run: |
              python3 -m pip install --upgrade pip
              python3 -m pip install -r requirements-client.txt
              python3 -m pip install 'pyinstaller>=6.11,<7'
          - name: PyInstaller build
            # Phase 1 is dry-run only — we gate on exit code, not universal2 or notarization.
            # RESEARCH Pitfall 4: macos-14 runners are arm64; accept arm64-only output.
            run: python3 build_client.py
          - name: Verify .app exists
            run: test -d dist/Teraguchi.app
          - uses: actions/upload-artifact@v4
            with:
              name: Teraguchi-app-arm64
              path: dist/Teraguchi.app
              retention-days: 7

      build-rpm-dryrun:
        name: RPM dry-run (Rocky 9)
        runs-on: ubuntu-latest
        container:
          image: rockylinux:9
        steps:
          - uses: actions/checkout@v4
          - name: Install rpmbuild
            run: |
              dnf -y install epel-release
              dnf -y install rpm-build rpmdevtools python3.12
          - name: Set up rpmbuild tree
            run: |
              rpmdev-setuptree
              # Create a minimal tarball so %prep has something
              mkdir -p /tmp/src/teraguchi-server-3.0.0
              cp -R server/ common/ /tmp/src/teraguchi-server-3.0.0/ || true
              tar -czf ~/rpmbuild/SOURCES/teraguchi-server-3.0.0.tar.gz -C /tmp/src teraguchi-server-3.0.0
              cp packaging/teraguchi-server.spec ~/rpmbuild/SPECS/
          - name: rpmbuild --nodeps --buildonly
            # --nodeps: runner container may not have ffmpeg-free available; Phase 6 fixes.
            # --buildonly: validate spec syntax + %prep/%build without %install actions.
            run: rpmbuild -bb --nodeps ~/rpmbuild/SPECS/teraguchi-server.spec
          - name: Verify SRPM exists
            run: |
              # Even with --nodeps, rpmbuild -bb produces an SRPM as a side-effect
              ls ~/rpmbuild/SRPMS/ || true
              ls ~/rpmbuild/RPMS/noarch/ || true
              echo "Phase 1 RPM dry-run complete (spec validates)"
    ```

    **Rationale for the dry-run semantics:**
    - `rpmbuild -bb --nodeps` builds from the spec without requiring runtime deps to exist on the container (ffmpeg-free is in Requires but we don't want CI to pull it). This catches syntax errors in the spec without failing on missing runtime deps.
    - `%files` is empty so no payload produced — that's intentional; Phase 6 populates it when real distribution lands.
    - The `Verify .app exists` step on macOS gates exit code. We DO NOT run `.app` to verify it launches (GHA runners can't reliably do a window-inspect; manual verification covered in VALIDATION.md §"Manual-Only Verifications").

    **Do NOT:**

    - Populate `%files` with actual file paths — that's Phase 6's work
    - Use `actions/upload-artifact@v3` — v4 is current
    - Ship a GPG key in this repo — Phase 6 publishes the key separately
